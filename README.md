### [Emperor's Decree](https://www.nexusmods.com/games/warhammer40kdarktide/mods/1281)
<img width="888" height="853" alt="image" src="https://github.com/user-attachments/assets/b12f10c4-7f45-493c-8387-c8aeba4a6463" />

Randomly chooses an operative and a saved loadout preset according to the divine will of the God-Emperor of Mankind.

**Options:**

**Operative Decrees**
- Randomize Operative on Start
- Auto-Reload Mourningstar on Switch
- Over Level 30 Characters Only
- Reroll Operative (Hotkey)

**Allowed Operative Classes**
- Allow Veteran
- Allow Zealot
- Allow Psyker
- Allow Ogryn
- Allow Hive Scum
- Allow Adamant
- Allow Skitarii

**Loadout Decrees**
- Also Randomize Saved Preset on Operative Reroll
- Skip Empty / Incomplete Loadout Presets
- Reroll Saved Loadout Preset (Hotkey)

**Decree Notifications**
- Show On-Screen Notifications
- Show Chat Messages

**Chat Commands:**
- `/decree`
- `/decree loadout`
- `/decree help`
